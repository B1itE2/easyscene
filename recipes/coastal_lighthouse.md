# 配方卡：海边灯塔 / Coastal Lighthouse

> 参数在 `coastal_lighthouse.json`。带 `between` / `choice` 的值由种子在安全范围内抽取。
> 标准参考图：`docs/reference/coastal_lighthouse.png`（preview，seed 3）

## 1. 一句话气质
日落时分，海岬悬崖上一座灯塔亮起，太阳贴着海平线，海面拉出一条金色光带；悬崖被侧逆光照成暖橙色，海水是深蓝。

## 2. 光（`golden_dusk` + 本风格覆盖）
| 项 | 取值 / 范围 | 理由 |
|---|---|---|
| 天空 | Poly Haven `qwantani_sunset_puresky`，自动旋转到太阳方向，亮度上限 6 | 画在 HDRI 里的太阳和场景太阳必须同方向；不限亮度会在海面反射成方块 |
| 太阳 | 相机朝向 ±14–24°（画面内但避开塔），高度 2–7°，2600–3300K | 低太阳才有海面金色光带和悬崖暖色轮廓 |
| 曝光 | −0.7 ~ −0.3 EV | 日落要压暗，天空才有颜色 |
| 灯室 | 3200K 400W 点光 + 两道发光体积光束（不耗光照计算） | 光束只用发光体积，不用聚光灯：快且不闪 |

## 3. 海面（可复用模块 `easyscene/water.py`）
- 近处：Blender 海洋修改器 8×8 块（每块 60m），按种子生成浪；时间轴驱动浪的运动
- 远处：到 60km 的平面，**粗糙度 0.35**（小浪远看就是粗糙表面）
- 近处海面随距离把粗糙度过渡到 0.35，远近衔接无缝
- 白浪：只在浪尖（泡沫属性 > 0.55）和礁石岸边（地形自动生成的岸线遮罩），蕾丝状，不是整片白

## 4. 悬崖
程序化海岬：岩石平台 → 主崖壁（冲沟 + 噪声）→ 圆润的草坡崖顶。法线朝上处是草，陡处是 `cliff_side` 岩石，水线附近是湿暗的岩石。

## 5. 可变范围（种子决定）
塔高 14–21m、条纹数 0/3/4/6、配色（红白 / 黑白 / 蓝白 / 纯白）、是否有守塔人小屋、海岬高度 10–22m、半径 24–38m、崖壁粗糙度、浪高、风速、浪向、相机方位、相机高度、太阳在左还是在右、雾的浓度、环绕角度 55–85°。

## 6. 构图规则
- 侧视：相机在海岬侧面的海面上空（高于崖顶 6–16m），塔衬在天空前
- 塔放在画面中间附近，太阳反光带在一侧
- 景深 f/5.6：风景片不做浅景深

## 7. 运镜：环绕展示（`orbit`）
绕塔扫过 55–85°，半径从 1.15 倍收到最终距离，高度从 +6m 降到最终高度；起停缓动；每帧检查离地高度。

## 8. 常见错误
| 现象 | 原因 | 防护 |
|---|---|---|
| 海平线上一块亮白方块 | 远处平面海像镜子反射太阳 | 远处海粗糙度 0.35 + 近处随距离过渡 |
| 天空的太阳和光照方向不一致 | HDRI 没旋转 | 自动找 HDRI 最亮点并旋转对齐 |
| 雾盒边缘一条亮边 | 逆光照亮体积盒侧面 | 雾在盒子外 30% 渐隐 |
| 塔像顶在一块平板上 | 悬崖是一道直墙 | 平台 + 崖壁 + 圆顶三段式剖面 |
| 海面满屏白色网纹 | 泡沫阈值太低 | 只保留浪尖 >0.55 的泡沫 |
| 画面发灰 | 雾太浓 | 海雾密度 ≤ 0.0018 |

## 9. 评分标准（满分 10，及格 7）
日落金光(3)、海面(3)、主体可读(2)、写实度(2)、光束(1)、曝光(1)。
