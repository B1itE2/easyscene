# 配方卡：雾气森林小木屋 / Foggy Forest Cabin

> 机器读取的参数在 `foggy_forest_cabin.json`，本卡解释每个参数**为什么这样定**。
> The machine-readable numbers live in `foggy_forest_cabin.json`; this card explains them.

标准参考图：`docs/reference/foggy_forest_cabin.png`（preview 画质，seed 7）

## 1. 一句话气质
清晨，冷蓝绿色的雾把森林分成一层层；一座旧原木小屋窗户透出暖黄的光，烟囱冒着淡淡的烟。安静、潮湿、有人在家。

## 2. 光（lighting preset `cold_fog_morning`）
| 项 | 取值 | 理由 |
|---|---|---|
| 环境光 | Poly Haven `kloofendal_misty_morning_puresky`，强度 1.6，饱和度压到 60%，乘冷色 (0.80, 0.93, 1.0) | 雾天天空本来就灰，去饱和避免"蓝天+雾"的假感 |
| 太阳 | 高度 12°，在相机前方偏 35°（逆光），5800K，强度 4.5，角直径 2.5° | 逆光才能在雾里打出光柱；角直径大一点让阴影柔 |
| 曝光 | +0.35 EV | AgX 下雾景偏暗，整体提一点，不靠后期硬拉 |
| 室内灯 | 2400K 点光源 ×4（主灯 140W），门口灯笼 2100K 6W | 暖色要明显比环境暖 3000K 以上，冷暖对比才出来 |

## 3. 色
- 雾：反照率 (0.80, 0.90, 0.93)，偏青；各向异性 0.35（前向散射，灯和太阳周围有光晕）
- 暗部不压死：最暗处保留蓝绿色细节
- 后期（ffmpeg）：暗部 +蓝绿、亮部 +暖，对比 1.04，饱和 0.92，暗角，轻颗粒

## 4. 雾的层次（核心）
- 地面雾密度 `fog`=0.022/m（能见度约 140m），`dense_fog`=0.034，`light_fog`=0.012
- 高度衰减 14m：地面浓、树冠以上淡
- 噪声打散（尺度 28m，幅度 ±55%）：雾成团成片，不是一面平墙
- 结果：近景 0–10m 清楚 → 中景木屋 20–30m 微雾 → 远景 50m+ 树逐渐只剩剪影 → 100m+ 隐入雾中

## 5. 材质
| 部位 | 素材（CC0） | 失败退回 |
|---|---|---|
| 原木 | `weathered_brown_planks`，纹理沿木头长度方向，偏冷灰褐，顶面长苔藓 | 程序化木纹 |
| 屋顶 | `roof_planks`，压暗去饱和，大量苔藓 | 程序化木板 |
| 烟囱、地基 | `stacked_stone_wall`，盒投影 | 程序化石块 |
| 地面 | `forrest_ground_01` + `brown_mud_leaves_01` 大尺度混合，加苔藓和湿斑 | 程序化泥土 |
| 树皮 | `pine_bark` | 程序化树皮 |
| 针叶 | 程序化：条带 + alpha 鱼骨纹针叶 + 透光 | — |
| 蕨类 / 石头 / 树桩 | Poly Haven `fern_02` / `rock_moss_set_01` / `tree_stump_01` | 程序化版本 |

## 6. 构图规则
- 三分法：木屋放在右三分线（`thirds_right`），用镜头平移（shift）实现，竖线不歪
- 默认 35mm、三分之四侧视（`three_quarter_left`），能同时看到山墙正面和侧墙
- 木屋占画面高度约 36%（`medium`）
- 烟囱自动放在相机能看到的那一侧
- 相机与木屋之间：地形压平、不种树、不放大石头
- 前景：画面一侧放一棵近树做框，底部角落放草和蕨类；景深 f/2.8 对焦木屋
- 烟柱所在区域不种树，保证烟衬在天空/远雾上

## 7. 常见错误（自查清单）
| 现象 | 原因 | 已有的防护 |
|---|---|---|
| 整张图发黑、没有雾 | 体积盒法线朝内，Cycles 判断不出相机在雾里 | 盒子统一外法线 |
| 小丘挡住木屋 | 随机地形起伏 | 相机→主体视线方向压平 |
| 近景树叶像棕榈叶 | 枝叶条带过大 | 小枝长度上限 0.85m |
| 烟看不见 | 烟和雾同色同亮度 | 烟用高反照率+高密度，并清空烟柱周围的树 |
| 大石头挡住主体 | 散布没避开视线 | 石头避开视线走廊 |
| 雾像一堵平墙 | 均匀密度 | 噪声打散 + 高度衰减 |
